# Compact Roxyz

## Etude de faisabilité

Ce dépôt contient l'étude d'une CNC basée sur la **[Roxyz](https://www.makerfr.com/2024/11/22/le-tuto-de-la-nouvelle-cnc-roxyz-est-en-ligne/)** de **[makerfr.com](https://makerfr.com)**. La Roxyz a été entièrement remodélisée sur **[FreeCAD 1.1](https://www.freecad.org/)** et modifiée pour la rendre le plus compact possible et rangeable dans un espace réduit.

## Feasibility Study

This repository contains a design study for a CNC based on the  **[Roxyz](https://www.makerfr.com/2024/11/22/le-tuto-de-la-nouvelle-cnc-roxyz-est-en-ligne/)** from **[makerfr.com](https://makerfr.com)**. The Roxyz has been entirely remodeled in **[FreeCAD 1.1](https://www.freecad.org/)** and modified to be as compact as possible, allowing it to be stored in a limited space.
